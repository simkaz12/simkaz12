# I build tools around the coding agents I use

The work spans instructions, memory, development interfaces, and a homelab. These repositories contain different parts of that setup.

| Project | Its place in the setup |
| --- | --- |
| [skillbook](https://github.com/simkaz12/skillbook) | How agents work: skills, delegation roles, hooks, and shared instructions for Claude Code and Codex. |
| [Tabularium](https://github.com/simkaz12/tabularium) | What agents remember: decisions, gotchas, and defects that should survive a conversation. |
| [T3 Code fork](https://github.com/simkaz12/t3code) | The development interface, extended with Tabularium memory tools and a memory tray, plus browser, terminal, and artifact changes. |
| [Pi Assistant](https://github.com/simkaz12/pi-assistant) | The homelab side: self-hosted infrastructure, MCP tools, and a Telegram agent. |
| [Arx](https://github.com/simkaz12/arx) | An earlier Rust agent-harness experiment. Unmaintained, with its own local memory implementation. |

Start with **skillbook** for the working practices, **Tabularium** for persistent agent memory, or **Pi Assistant** for the homelab.

These are personal projects with different levels of completeness. Each README explains what you can run or reuse.
